# Phylomic

Bulk RNA-seq analysis and reporting for research labs: standardized, reproducible and fully documented.

## Flagship analysis

**[Bleomycin lung fibrosis, GSE301216](https://github.com/phylomic/phylomic-rnaseq-flagship)**
A complete public reanalysis of a mouse model of pulmonary fibrosis: the pipeline, a verification gate
(91 of 91 checks), publication-quality figures and the full report.
